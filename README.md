# dileepkumar-gith-Pizza-Sales-Data-Analytics
🍕 Pizza Sales Data Analytics Project

This project focuses on analyzing pizza sales data to extract meaningful business insights using SQL and Microsoft Excel.

SQL was used to perform data querying, aggregation, and KPI calculations such as Total Revenue, Average Order Value, Total Orders, and Total Pizzas Sold. The processed data was then visualized in Excel using Pivot Tables and charts to build an interactive dashboard.

The analysis includes daily and hourly sales trends, sales distribution by pizza category and size, and identification of top-performing and underperforming products. A custom dashboard background was designed to improve clarity and visual storytelling.

This project represents my first step into data analytics and demonstrates foundational skills in SQL, data analysis, and dashboard creation. Future improvements include converting the dashboard into Power BI for advanced visualization.
